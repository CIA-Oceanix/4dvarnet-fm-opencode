## 2026-09-28: ETKS (ensemble transform Kalman smoother) on the unlocalised ETKF — PR 1

**Summary:** Adds `ETKS(ETKF)`. It runs the ETKF unchanged, records each analysis's ensemble-space transform (w, T), and applies later transforms retrospectively to the stored ensemble. Options:
- `lag` (None = full window);
- `retro_inflation`: `"correct"` (default), which scales the factor of an analysis m inflations later by λ^(−m) and uses the pre-inflation state at analysis times, or `"none"`, limited to `lag <= 2`.

Not yet wired into `evaluation/run_l96.py` / `evaluate_all_l96.py`; that is PR 2, with validation tuning and the benchmark metric.
**Files modified:**
- `evaluation/baselines.py` — the transform-recording hook in `ETKF.assimilate` / `assimilate_batch`. When `_record_transforms` is set it appends copies of the already-computed `w` and `Tmat` and flags windows where the NaN guard fired; the filter arithmetic is unchanged. Also `_etks_factor`, `_etks_smooth` and `ETKS`.
  - `ETKS` raises on localisation and `etkf_additive > 0`.
  - Windows touched by the NaN guard are returned unsmoothed and listed in `unsmoothed_windows`.
  - `crps` / `es` of a smoothed result score the smoothed ensemble.
- `tests/test_baselines_etks.py` (new) — the plan's tests 1–10:
  - hook no-op;
  - lag 0 = filter;
  - smoother = filter at and after the last analysis;
  - exact match to a Kalman/RTS smoother on a linear-Gaussian model (λ = 1, od < N);
  - single vs batch agreement;
  - NaN obs channels, with smoother < filter RMSE;
  - `correct` = `none` at λ = 1;
  - the `correct` factor equals the Kalman update with λ^(−m)-scaled cross-covariance, plus its c = 0 / c = 1 limits;
  - flat in lag;
  - argument validation and the NaN-window path;
  - slow: reproduces the prototype on P1 windows 0–19.
- `docs/plans/tech/l96_etks_smoother.md`, `docs/README.md` — status: PR 1 implemented.
