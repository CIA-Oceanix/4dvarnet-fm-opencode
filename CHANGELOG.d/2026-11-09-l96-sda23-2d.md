## 2026-11-09: SDA2 / SDA3-fix priors on the 2D L96 backbone

**Summary:** The conditional SDA priors on the 2D (time x sector) circular backbone (`MonaiConditionalPriorCFM2D`): the forcing and the 8 parameters enter every sector as extra channels, so the prior stays equivariant to cyclic sector shifts. Configs `L96B_sda{2,3fix}_monai2dM_ep1200` inherit the 1D 1200-epoch recipe and swap only the backbone. Batch scripts train 3 seeds and run the benchmark guided evaluation and the DirectUNet-2D hybrids; a second one runs the evaluations that bring these rows and the 2D seeds 2-3 into the P1 tables (hybrid guidance-weight validation, variance re-evaluation).
**Files modified:**
- `models/monai_unet_l96_2d.py`, `train.py`, `training/lightning_module.py`: the 2D conditional prior.
- `config/experiment/L96B_sda2_monai2dM_ep1200.yaml`, `config/experiment/L96B_sda3fix_monai2dM_ep1200.yaml`: the new configs.
- `batch/run_l96b_sda23_2d.sbatch`, `batch/run_l96b_sda1_2d.sbatch` (`HYBRID=0`): training and benchmark evaluation.
- `batch/run_l96b_2d_sda23_eval.sbatch`: the P1 evaluations.
- `tests/test_monai_unet_l96_2d.py`: tests for the new prior.
**Rationale:** P1 Table 5 needs SDA2 / SDA3 with the backbone of the other learned rows. The 1D SDA1 prior stood in for them until now.
