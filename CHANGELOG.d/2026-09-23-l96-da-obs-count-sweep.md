## 2026-09-23: L96 DA obs-count sweep, batched-EnKF fix, opt-in DA fast weights

**Summary:** ETKF/EnKF sweep over the number of observation times per window (5-300, random times with step 0 always observed, all 24 channels, 10 P1 windows x 5 draws, S0/S1) plus a `reg30` cell tying it to the P1 table. Fixes a batched-EnKF bug that broke every irregular-time run, and adds an opt-in `--da-fast-weights` that passes each window's `fast_weights` to the DA model.
**Files modified:** `eval_da_obs_count_l96.py` — new, one sweep cell per call; `reports/l96/generate_l96_da_obs_count_report.py` + `reports/l96/outputs/l96_da_obs_count_dafw.{md,png}` — report; `batch/run_l96_da_obs_count.sbatch` — one array task per cell; `batch/run_l96_da_s0c_dafw.sbatch` — full P1 DA rerun with DA fast weights; `evaluation/baselines.py` — batched EnKF analysis restricted to the windows observed at step t, `_expand_batch_params` repeats per-window `(B, k)` fast weights over members (ETKF/EnKF); `evaluation/run_l96.py`, `evaluate_all_l96.py` — `da_fast_weights` / `--da-fast-weights` (cache suffix `_dafw`); `tests/test_da_obs_count_l96.py` — 9 tests.
**Rationale:** (1) Batched EnKF updated every window as soon as one window had an obs at step t; windows without one got NaN innovations, `nan_to_num`'d into a collapsed ensemble. Invisible on the regular grid (all windows share obs times), so P1 EnKF numbers and the golden values are unaffected. (2) P1's DA path never passed per-window `fast_weights`, so S0 DA ran with unweighted fast coupling; the corrected rerun (job 54716, 200 windows) gives S0 ETKF 0.821 (P1 0.866), EnKF 0.834 (0.894), Strong-4DVar 0.703 (0.738), S1 unchanged. Default stays off so existing caches and tables are untouched. (3) Sweep: ETKF S0 RMSE 1.07 (5 obs) -> 0.88 (30 random) -> 0.73 (150); the regular 30-time grid (0.81) beats 30 random times; EnKF degrades past ~100 obs because the 30-obs-tuned inflation 2.0 is applied per analysis and compounds with obs frequency.
**Verification:** `pytest tests/ -m "not slow"` pass (incl. DA golden values); `ruff check` on touched files clean.
