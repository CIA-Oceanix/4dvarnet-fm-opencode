## 2026-09-27: L96 — FDV under the benchmark default (P2 plan + Phase 0)

**Summary:** Plan for adding the FDV1 and FDV2 `subgrad+state` unrolled solvers (M and S tiers, 3 seeds) to the L96 benchmark-default recipe for P2, plus the Phase 0 code: FDV now masks observations per element, and `eval_neural_l96.py --n-outer` defaults to the solver's own `N_outer`.
**Files modified:** `models/fourdvarnet.py` — new `_observed_mask` (time mask AND `isfinite(obs)`), used by `FourDVarNetSolver.forward`, its var-cost loss and `FourDVarNetPredictStateCFM.forward`; `eval_neural_l96.py` — `--n-outer` default `None` -> `default_n_outer(model)`; `config/experiment/L96B_fdv1_monai{M,S}.yaml`, `config/experiment/L96B_fdvsubgrad_monai{M,S}.yaml` — new; `docs/plans/analysis/l96_p2_fdv_benchmark.md` — new plan; `docs/README.md` — index entry; `batch/run_l96b_fdv_seeds.sbatch` — Phase 1 runs; `tests/test_fourdvarnet.py`, `tests/test_eval_neural_l96_n_outer.py` — regression tests; `tests/test_neural_inference.py` — mock `obs_mask` fixed from (B,) to the real (B,T) shape (the eager mask exposed it).
**Rationale:** The benchmark-default random observing system keeps `obs_mask` per timestep and marks dropped fast channels NaN. FDV zero-filled them under a (B,T,1) mask, so `subgrad+state`'s `g_obs` (and the grad modes' obs cost) treated every dropped channel as observed at 0. The mask is unchanged on the regular grid (all channels of an observed row finite), so existing checkpoints and numbers are unaffected. The `--n-outer` default of 1 once silently gave FDV1 RMSE 3.47.
**Verification:** `pytest tests/test_fourdvarnet.py tests/test_fourdvarnet_monai.py tests/test_eval_neural_l96_n_outer.py -m "not slow"` -> 177 passed; 2-epoch train + 25-window random-layout eval smoke test of all four configs (all rc=0, n_outer auto-set to 10, RMSE 1.25-1.32 after 2 epochs); `batch/run_l96b_fdv_seeds.sbatch` added for Phase 1 (not submitted).
